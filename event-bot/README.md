# event-bot
단순한 REST API의 RPS 또는 TPS를 측정하는 목적이라면, 부하 발생기를 직접 개발하기보다 nGrinder나 JMeter와  
같은 전문 도구를 사용하는 것이 더 효율적일 수 있다.  

그러나 이번 프로젝트의 요구사항은 Kafka에 특정 이벤트를 지정한 횟수만큼 발생시키거나, 확률적으로 잘못된 데이터를  
생성하여 오류 검출 시나리오를 테스트하는 등 보다 다양한 동작을 필요로 한다. 이러한 요구사항에 유연하게 대응하기  
위해 웹 기반 관리자 기능을 제공하고, 부하 발생 옵션을 동적으로 수정하고 실행할 수 있는 구조로 구성할 예정이다.  

또한 본 구성은 단순한 부하 테스트 도구라기보다 **비즈니스 정합성 검증을 위한 시나리오 데이터 생성기**에 가깝기  
때문에, Spring Boot 기반으로 직접 구현하는 것이 더 유연하고 강력한 선택이라고 판단하였다. 특히 확률적으로  
오류 데이터를 생성하는 기능은 정산 시스템의 Reconciliation(대조) 로직을 검증하기 위해 필수적인 요소이다.  




Loop + Sleep 방식 보다도 rateLimit 기술을 사용해서 부하 발생기에 요청 수를 통제하는 방식도 고려해볼만 하다.
