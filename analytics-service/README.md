# analytics-service
분석 서비스는 다양한 이벤트 로그를 기반으로 통계 정보 및 대시보드 데이터를 제공하는 서비스이다.  
이 서비스의 핵심은 실시간 스트림 처리(Kafka Streams)와 OLAP 쿼리이며, OLAP 성격의 데이터 저장소로  
**ClickHouse를 사용**한다.  
ksqlDB(Kafka Streams)만으로 구성된 경우, 오늘의 총 매출액이나 최근 1시간 인기 상품 TOP 10과 같이  
사전에 정의된 지표를 실시간으로 조회하는 용도에는 적합하다. 또한 현재 상태 중심의 간단한 집계에는  
ClickHouse 없이도 충분히 구현할 수 있다.  
그러나 본 분석 서비스에서는 사용자가 대시보드에서 날짜 범위를 자유롭게 변경하거나 다양한 필터를 적용하는 등  
사전 집계되지 않은 조회가 필요하다. 또한 수개월에서 수년치에 이르는 대용량 데이터를 저장하고 조회해야 하는  
요구사항이 있기 때문에, 이러한 요구를 충족하기 위해 ClickHouse를 도입한다.  

따라서 분석 서비스의 데이터 처리 파이프라인은 다음과 같이 구성된다.  
우선 ksqlDB에서 데이터를 가공(ETL)한 뒤, 고정 집계 데이터는 KTable을 통해 State Store(RocksDB)에 저장한다.  
이후 최종 집계 결과를 ClickHouse에 적재하는 구조로 설계하였다.
